## チャンネル指定

各チャンネルは行頭でコロンを使って指定します。

| 記法 | チャンネル | 音源タイプ |
|------|-----------|-----------|
| `A:` または `CH1:` | チャンネル1 | パルス波（スイープ機能付き） |
| `B:` または `CH2:` | チャンネル2 | パルス波 |
| `C:` または `CH3:` | チャンネル3 | 波形メモリ |
| `D:` または `CH4:` | チャンネル4 | ノイズ |

### 例

```
A: CDEFGAB     ; チャンネル1でドレミファソラシを再生
CH2: CDEFGAB   ; チャンネル2でドレミファソラシを再生
```

## 音符と休符

### 音符

| コマンド | 音名 |
|---------|------|
| `C` | ド |
| `D` | レ |
| `E` | ミ |
| `F` | ファ |
| `G` | ソ |
| `A` | ラ |
| `B` | シ |

### 変化記号

| 記号 | 意味 | 例 |
|------|------|-----|
| `+` または `#` | シャープ（半音上げ） | `C+` `D#` |
| `-` | フラット（半音下げ） | `D-` `E-` |

### 休符

| コマンド | 説明 |
|---------|------|
| `R` | 休符 |

### 例

```
C D E F G A B    ; ドレミファソラシ
C+ D# F+ G+ A+   ; シャープ付き
R4 C R4 D        ; 休符を含む
```

## 音長

音符・休符の後に数値を付けて長さを指定します。

| 数値 | 音長 |
|------|------|
| `1` | 全音符 |
| `2` | 2分音符 |
| `4` | 4分音符 |
| `8` | 8分音符 |
| `16` | 16分音符 |
| `32` | 32分音符 |

### デフォルト音長 (L)

`L<n>` でデフォルトの音長を設定します。以降、音長を省略した場合はこの値が使用されます。

```
L8         ; デフォルトを8分音符に設定
CDEF       ; 全て8分音符で再生
C4 D E F   ; Cは4分音符、D E Fは8分音符
```

### 付点

`.` を付けると1.5倍の長さになります（付点音符）。

```
C4.    ; 付点4分音符（4分音符 + 8分音符の長さ）
C2..   ; 複付点2分音符
```

## オクターブ

### オクターブ設定 (O)

`O<n>` でオクターブを設定します（1〜8）。デフォルトは4です。

```
O4 CDEFG   ; オクターブ4でドレミファソ
O5 CDEFG   ; オクターブ5でドレミファソ
```

### オクターブ上下

| コマンド | 説明 |
|---------|------|
| `>` | オクターブを1つ上げる |
| `<` | オクターブを1つ下げる |

```
O4 CDE >CDE <CDE   ; O4でCDE、O5でCDE、O4でCDE
```

## テンポ

`T<n>` でテンポ（BPM: Beats Per Minute）を設定します。デフォルトは120です。

```
T120    ; 120 BPM
T90     ; 90 BPM（ゆっくり）
T180    ; 180 BPM（速い）
```

---

## 音量

`V<n>` で音量を設定します（0〜15）。デフォルトは15です。

```
V15 CDEF   ; 最大音量
V8 CDEF    ; 中程度の音量
V0 CDEF    ; 無音
```

## 音色設定

### デューティ比 (@) - CH1/CH2用

パルス波チャンネル（CH1/CH2）のデューティ比を設定します。

| 値 | デューティ比 | 音の特徴 |
|----|-------------|---------|
| `@0` | 12.5% | 細い音、金属的 |
| `@1` | 25% | やや細い音 |
| `@2` | 50% | 標準的な矩形波 |
| `@3` | 75% | 太い音（25%の反転） |

```
A: @0 CDEFG   ; 12.5%デューティ
A: @2 CDEFG   ; 50%デューティ（デフォルト）
```

### 波形プリセット (W) - CH3用

波形メモリチャンネル（CH3）の波形を設定します。

| 値 | 波形 | 説明 |
|----|------|------|
| `W0` | 三角波 | 柔らかい音 |
| `W1` | ノコギリ波 | ブライトな音 |
| `W2` | 矩形波 | 硬い音 |
| `W3` | サイン波 | まろやかな音 |
| `W4` | ベース | 低音向け |

```
C: W0 CDEFG   ; 三角波
C: W3 CDEFG   ; サイン波
```

## ループポイント

`$` でループポイントを設定します。ループ再生が有効な場合、曲の終わりに達すると `$` の位置に戻って再生を続けます。

ループポイントが設定されていない場合は、従来通り曲の最初に戻ります。

### 用途

- イントロ部分をスキップしてメイン部分のみをループ
- ゲームBGMなどで導入部の後にループする曲の作成

### 例

```
; イントロ → ループ開始 → メインループ
A: T120 O4 L4
   CDEF        ; イントロ（1回のみ再生）
   $           ; ここがループポイント
   GFED GFED   ; ループ時はここから再生
```

### 複数チャンネルでの使用

各チャンネルに個別にループポイントを設定できます。ループ時は各チャンネルがそれぞれのループポイントに戻ります。

```
A: T120 O4 L4
   CDEF $ GGGG GGGG

B: T120 O3 L4
   R1 $ CCCC CCCC
```

---

## コメント

`;` または `//` 以降はコメントとして無視されます。

```
; これはコメントです
A: CDEFG   ; 行末コメント
// これもコメント
```

## サンプル

### 基本的なメロディ

```
A: T120 @2 V12 O4 L4
   CDEFGAB>C
```

### きらきら星（2声）

```
; きらきら星

A: T100 @2 V12 O4 L4
   CCGGAAG2 FFEEDDC2
   GGFFEED2 GGFFEED2
   CCGGAAG2 FFEEDDC2

B: T100 @1 V8 O3 L4
   E2G2C2E2 D2F2E2C2
   E2D2C2B-2 E2D2C2B-2
   E2G2C2E2 D2F2E2C2
```

### 4チャンネル使用

```
; 4チャンネルBGM

A: T140 @2 V12 O4 L8
   EG>C<B AG E4
   DC<A>C <G4 R4

B: T140 @1 V10 O3 L8
   C4E4 G4E4
   F4A4 E4C4

C: T140 W0 V12 O3 L4
   C2 G2 A2 G2

D: T140 V6 O2 L4
   C R E R G R E R
```

## 内部仕様

### ティック

- 全音符 = 96ティック
- 4分音符 = 24ティック
- ティック/秒 = (テンポ × 24) / 60

### 周波数計算

A4 = 440Hz を基準に、各音は以下の式で計算されます：

```
周波数 = 440 × 2^((半音数 - A4からの距離) / 12)
```
